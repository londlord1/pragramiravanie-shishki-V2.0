# Сервис бронирования номеров гостиницы «Сладкие сны»

Учебный проект по дисциплине **МДК 03.02 «Разработка кода информационных ресурсов»**.
Реализует сервис бронирования номеров гостиницы, включая каталог номеров с
фильтрацией, отправку заявок на бронирование и панель администратора.

## Состав заданий

- **Практическая работа №1** — анализ предметной области (диаграмма прецедентов и классов).
- **Практическая работа №3** — проектирование базы данных и загрузка прототипов страниц на платформу контроля версий.
- **Практическая работа №4** — доработка сервиса: валидация дат, блокировка занятых периодов, панель администратора.

## Стек

- PHP 5.6+ (серверная валидация, фильтрация, сессии)
- MySQL 5.7+ / 8.0
- Bootstrap 5, jQuery (шаблон)

## Структура

```
├── config.php      # подключение к БД и настройки администратора
├── database.sql    # схема БД + начальное наполнение каталога
├── index.php       # каталог номеров с серверной фильтрацией
├── order.php       # бронирование номера (валидация, занятые периоды)
├── login.php       # вход администратора (hotel123)
├── admin.php       # панель управления: заявки и каталог номеров
├── logout.php      # выход администратора
├── css/ js/ fonts/ img/   # ресурсы шаблона
└── шаблон/         # исходные макеты страниц (прототипы)
```

## Настройка

1. Создайте базу MySQL в панели управления хостингом и импортируйте `database.sql`.
2. Впишите данные подключения в `config.php` (`DB_NAME`, `DB_USER`, `DB_PASS`).
3. Сгенерируйте хеш пароля администратора и подставьте его в `ADMIN_PASS_HASH`:
   ```
   php -r "echo password_hash('adminHotel', PASSWORD_DEFAULT);"
   ```
4. Откройте сайт — каталог на `index.php`, вход администратора на `login.php`
   (логин по заданию — `hotel123`).
